FoRgE typeface v2 is built by GitHub Actions from the SIL Open Font License (OFL) Barlow Condensed family, with custom FoRgE and FoRgE Coin glyphs added at U+E000 and U+E001.

Seven real static weights are generated: Light 300, Regular 400, Medium 500, SemiBold 600, Bold 700, ExtraBold 800, and Black 900. Each weight is exported as TTF, CFF-based OTF, and WOFF2.
